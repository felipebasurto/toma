# Toma

⇧⌘4, pero en vídeo.

1. **⌥⇧⌘4** y arrastra una zona. Igual que ⇧⌘4: Espacio la mueve, ⇧ fija un eje, ⌥ crece desde el centro, Esc cancela.
2. Graba desde que sueltas. Para con **⌥⇧⌘4** o con **■ 0:07** en la barra de menús.
3. Aparece una miniatura abajo a la derecha: **MP4 · HEVC · GIF**. Pulsa uno, o no hagas nada y se guarda en el último formato que usaste. El icono de copiar lo deja en el portapapeles. Arrástrala a cualquier app para soltar el archivo ahí. La × la descarta.

En el menú de la barra: **Guardar en** (carpeta), **Tamaño del GIF** (Nítido / Ligero) y **Sonido** (sin sonido, sonido del Mac, o Mac y micrófono).

| | Peso típico (4 s, 1120×720, texto desplazándose) |
|---|---|
| Grabación original | 2,5 MB |
| MP4 (H.264) | 0,46 MB |
| HEVC | 0,25 MB |
